> 传递==拷贝。需要记住的是在参数传递过程中的拷贝动作，而不是关注到底是“值传递”还是“引用传递”。

```java
public static void main(String[] args) {
    int x = 10;
    foo(x);
    System.out.println(x); // 10

    //
    House h1 = new House();
    h1.setColor("red");
    bar1(h1);
    System.out.println(h1.getColor()); // yellow

    //
    House h2 = new House();
    h2.setColor("red");
    bar2(h2);
    System.out.println(h2.getColor()); // red
}

public static void foo(int i) {
    i = 11;
}

public static void bar1(House h) {
    h.setColor("yellow");
}

public static void bar2(House h) {
    h = new House();
    h.setColor("yellow");
}
```

- Case A，原始类型
  - Line 2：有一张小纸条，上面写着数字10。
  - Line 3：小纸条被复印了一份，给了foo()方法。
  - 两张小纸条，互不影响，互相独立。

- Case B，引用类型
  - Line 7：有一张小纸条，上面写着地址0x101。
  - Line 8：一个粉刷匠按照小纸条上所示，找到了位于0x101的房子，并把它刷成了红色。
  - Line 9：小纸条被复印了一份，给了bar1()方法。
  - Line 24：另一个粉刷匠按照复印的小纸条上所示，同样找到了位于0x101的房子，并把它刷成了黄色。
  - 那么，现在位于地址0x101上的房子是什么颜色？

- Case C，引用类型
  - Line 13：有一张小纸条，上面写着地址0x201。
  - Line 14：一个粉刷匠按照小纸条上所示，找到了位于0x201的房子，并把它刷成了红色。
  - Line 15：小纸条被复印了一份，给了bar2()方法。
  - Line 28：复印的小纸条上的地址被涂改成0x301。
  - Line 29：另一个粉刷匠按照复印的小纸条上所示，找到了位于0x301的房子，并把它刷成了黄色。
  - 那么，现在位于地址0x201上的房子是什么颜色？
